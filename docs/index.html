05 · Go-to-market, metrics & risks

Start with one dense network. Measure collaborations, not likes.

North Star

New collaborations / week
knock accepted → merged PR in 30 days, verified on GitHub
Projects posted with a clip
Knocks sent per active builder
Knock → accepted rate
Accepted → first merge rate

Counter-metrics I watch

🧯 Knocks per maintainer / week, mute rate
🤖 Share of knocks flagged low-effort / AI
📈 % of knocks going to the top 1% of projects
👀 Clip views with no repo action (vanity)

Risks

1 Cold start. Campus networks where one persona plays both sides.
2 Slop moves to knocks. Maintainer caps, context required, vouch-weighted ranking. In MVP.
3 GitHub copies it. Distribution via Shorts + Android, and the graph compounds.
4 Google’s social track record. Narrow job, GitHub-first, open data export.
5 Performative content. Every clip must link to real commits.
